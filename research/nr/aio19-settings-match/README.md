# AIO19 NR setting match

The user requested cloning AIO19 NR settings into DvaKolbas for comparison, then approved changing both to the shared **Before/preset 0** configuration. Skyrim and MO2 were closed before editing. Both original INIs were backed up; the receipt records their before/after hashes and exactly changed keys. Libraries, the mod list, MO2 configuration, profile files and other mod files were unchanged.

AIO19 has `ChainVersion=1` and `PassCount=1`. Its enabled `[NR PASS 1]` supplies the effect controls; **Style=1** is authoritative for that pass, while the older global `mDLSSNRStyle=0` remains migration data. The active pass has intensity/tone/structure/skin strengths 1.0, AutoSkin false, MaskGroups false and all groups disabled. Dva copies those active values and the global reconstruction controls. One enabled native SDR pass, Auto resolve, ratio transfer/color strengths 1, max ratio 2, white point 1, UI correction off and HDR off are shared. AIO's input scale 0 means no downsampling; Dva uses the equivalent canonical scale 1.

AIO19 changes only `mDLSSNRBeforeUpscaling=true` and `mDLSSNRPreset=0`. Dva sets its corresponding Before/preset-0 controls, copies the active pass tuning and disables `NRStableColors`, so the comparison uses raw vendor grading. Appearance presets, peripheral compression, fused preparation and combat pass reduction are disabled in Dva. The second pass is inactive. IDs, customization flags and disabled AIO mask groups have no active rendering counterpart to copy.

This is **NR-control parity**, not full image or host parity. AIO19 remains FSR3.1 Native with sharpening/auto-exposure off and ReShade before upscaling. Dva remains DLAA with sharpening/auto-exposure on and ReShade after upscaling. The retained NR DLL hashes also differ; no runtime was replaced. Those differences are preserved explicitly in the receipt and must be controlled before attributing all image/FPS differences to the NR host. This configuration change does not establish gameplay acceptance or complete another NR implementation milestone.
