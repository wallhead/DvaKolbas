# Version 1.3 ENB INI correction

Historical configuration-only delivery, superseded by
[automatic NR selection](2026-10-08-automatic-nr-selection.md).

The public release selected DLAA, but AMD policy switches that saved preference
to FSR. Its inactive FSR preference had `SourceColorEncoding=Unknown`, which
then became an invalid active startup configuration. The ENB release now sets
FSR encoding explicitly to `Gamma22`. Parsing and validation still reject
missing/unknown active encodings; no renderer-side guessing was added.

The rest of the startup settings were audited against the bundled payloads and
the installed working SDR configuration. Two more related defaults needed
correction: Legacy NR pointed to a runtime absent from this archive, and the
Community SDR byte path was disabled. The release now selects
`Runtime=Community`, `SourceColorEncoding=Gamma22`, `SdrBytesTrial=true`.
NR itself remains disabled. The optional Legacy path is documented as an
unbundled, separately installed runtime, ignored in Community mode.

Preserved defaults and portable settings:

- DLSS Native (DLAA), FSR Native, analytical FSR3 upscaling/FG preference.
- FG Auto/off, NR off, HDR off; one native NR pass with preset 0 and no UI correction.
- Dedicated native UI and camera jitter for temporal reconstruction.
- NR profile Auto; catalog and driver-core overrides blank; relative Streamline path.
- Appearance presets, dynamic resolution, direct-output experiments and detailed logging off.
- Existing sharpening and other unrelated tuning values preserved.

Gamma22 is the explicit ENB SDR configuration choice, not a universal encoding
claim. Users with another producer must select its actual encoding for FSR/NR.
AMD continues to disable NR through GPU policy. The private installed HDR trial
and all MO2 profile/launch settings were left untouched.
