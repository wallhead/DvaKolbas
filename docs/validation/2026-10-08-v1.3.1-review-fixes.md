## GPU family discovery

Public NVAPI architecture discovery is matched to the actual DXGI render LUID, independently for D3D11 inspection and the D3D12 NR owner. Turing/Ampere select the RTX 20/30 compatibility model; Ada/Blackwell select the shared RTX 40/50 model. No individual laptop PCI ID is required when discovery succeeds. RTX product identity excludes GTX 16 cards, which also use Turing. Missing NVAPI permits the previous reviewed PCI fallback; successful incompatible evidence, ambiguous mappings, multi-node GPUs and future architectures are rejected. Model hashes, file leases and actual-adapter ownership checks are preserved.

ABI and IDs were checked against the [official NVAPI header](https://github.com/NVIDIA/nvapi/blob/main/nvapi.h) and [interface table](https://github.com/NVIDIA/nvapi/blob/main/nvapi_interface.h). No SDK binaries or reference headers were added to the release.

## Configuration

A saved `[NeuralRendering Advanced] Runtime=Legacy` emits a migration notice before removal, pointing to `[Debug] NRLegacyRuntime`. Explicit diagnostic selection remains available. Raw fallback defaults match the schema: FG disabled, SDR byte input enabled, DLSS preset K (11), sharpness 0.672 and Native anti-aliasing. Missing/unreadable startup INIs fail with installation instructions rather than guessing a producer color domain. Raw source-encoding defaults remain Unknown intentionally; the packaged ENB INI explicitly provides Gamma22. README now explains Linear/Gamma22/SRGB for other producers.
