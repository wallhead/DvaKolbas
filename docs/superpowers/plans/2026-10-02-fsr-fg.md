# FSR Frame Generation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Preserve inline execution in this chat; do not dispatch implementers without user authorization.

**Goal:** Add opt-in FSR SR plus FSR FG with correct native UI and safe D3D11/D3D12 presentation, proven in a standalone fixture before Skyrim deployment.

**Architecture:** Keep Skyrim's stable D3D11 wrapper and producer identity. Feed shared scene/guides and completed UI to the official AMD D3D12 interpolation swapchain, which owns pacing. Keep ordinary SR and NVIDIA presentation independently selectable.

**Tech Stack:** C++23, D3D11.4/D3D12/DXGI, typed dynamically loaded FidelityFX SDK v2.3.0 APIs, CMake/CTest, PowerShell.

**Spec:** [Approved FG design](../specs/2026-10-02-fsr-fg-design.md), approved by the user's “proceed.” This plan still requires review before implementation.

## Global Constraints

* SDK commit `60f4ea81909200d8542eca14dccb2628b763a9a3`; archive SHA-256 `f90890b9323bb2f4f2404ac4cdc9395e8495ecdac6f7aa0bcdf1ad1848422273`.
* First stage: FSR SR plus FSR FG, one generated frame per accepted source frame, SDR, fixed extents, dedicated UI, Analytical SR, no NR. Other upscaler/FG combinations, HDR, dynamic resolution, CS ownership and async-compute optimization remain unavailable.
* Preserve upscaler numbers DLSS=0, DLAA=3, FSR=4; generation values 0 ordinary and 1 NVIDIA. Reserve 2 for FSR only after Task 2's history audit.
* One HWND presenter, one temporal upscale and one ReShade execution per source frame. Publish game targets at factory interception; defer full feature initialization until original D3D11 creation/startup Present completes.
* Game-facing `GetDevice`/`GetBuffer` retain D3D11 types and producer identity on the AMD path. No D3D12-to-D3D11 casts, native-buffer cache reuse, adapter-zero fallback or relaxed resource ownership checks.
* Source IDs agree across prepare/configure/dispatch; time is milliseconds. Generated presents never advance source IDs. Loading/spatial/invalid frames suppress generation and reset reentry.
* Completed UI only; SDK internal UI buffering; premultiplied alpha. Worker threads never call Skyrim, ImGui or D3D11's immediate context.
* Retire producer, dispatch, guide, scene and presentation/UI readers. No fake completion, per-frame allocation, CPU readback, sleeps or routine full-device drain in production.
* `TRP_ENABLE_FSR_FG` defaults OFF and requires `TRP_ENABLE_FSR=ON`. SR-only packages and FSR-disabled builds require no FG files. Only FG packages include the additional runtime.
* Keep the installed `8e78f5136772` SR DLL/INI while Tasks 1–7 run. User launches Skyrim manually; preserve MO2 launch/profile settings. Push to `wallhead/codex/fsr-sr` is authorized.
* Available GPU: RTX 4080 Super. AMD/Intel acceptance is untested. Exclude only the three unavailable Graphics Tools cases; do not retry installation.
