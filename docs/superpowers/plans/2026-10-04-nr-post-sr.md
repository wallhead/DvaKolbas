# NR post-SR source stage implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans inline. Steps use checkbox (`- [ ]`) syntax. Preserve completed work; no per-task agents.

**Goal:** One live-selectable NR pass before or after DLSS/DLAA/FSR upscaling, with the enhanced real source fed to optional FG.

**Architecture:** Reuse the pinned shared owner/Stage and add a real-source post-upscale adapter. Both providers publish enhanced source color to existing FG before native UI composition; no per-generated-image NR adapter.

**Tech Stack:** Windows x64, C++23/MSVC, D3D11/D3D12 resources/fences, pinned NGX/FidelityFX/Streamline, CMake/CTest and PowerShell.

**Spec:** [Revised design](../specs/2026-10-04-nr-post-sr-design.md), reflecting the owner's requested 2026-10-04 ordering. Supersedes the 2026-10-03 post-FG placement plan. No implementation or installation is claimed by this revision.

## Global constraints

- Exactly one pass per eligible real source, Before or After SR; both feed optional FG.
- After means post-SR/pre-FG, including FG off. Generated images inherit enhanced sources; no separate NR pass.
- Retain live toggles/placement, one process-latched GPU-specific model and explicit AMD unsupported status.
- Preserve accepted full tone/styles, qualified SDR-byte domain, alpha, native UI and ENB/ReShade ownership.
- Prove display-size real guides and enhanced FG-source ownership; reject stale, foreign and generated packets.
- No uncertain release, fake completion or duplicate legacy pass; preserve accepted presenter pacing/workers.
- Preserve installed Before trial/INI/MO2 settings. No GPU probes alongside Skyrim, installation while Skyrim/MO2 runs, or game launch/kill.
- Exclude only unavailable Graphics Tools tests NativeUIComposition, NativeUIBlendState and NeuralPeripheralPixels; exclusions are not passes.
- Eight milestones retained. Tasks 1/2/3/4 are complete for the bounded native-size source stage and FSR source/presentation route; **4 of 8**. True post-FG work is deferred, not counted as tested.

**2026-10-04 execution scope:** initial After admission is native-size DLAA or FSR Native AA. Nearest-guide scaling failed independent geometry. Reduced-resolution After remains a future qualification gate; current scaled SR retains Before support. The shared source stage has native/ReShade pending encoder/resize proof. Tasks4-6 are wired but retain actual vendor/generated-output/external reader/lifecycle gates. [Evidence](../../../research/nr/post-sr/SOURCE_STAGE.md).

## Review focus

1. FSR displays NR output but FG uses old cached color: observe enhanced FG source (Task 4).
2. After accidentally requires FG enabled: one source evaluation with FG off (Tasks 4-5).
3. Live Apply mixes old/new appearance or deadlocks: retire readers, freeze source settings and reset histories (Task 6).
4. Display color uses unscaled render guides: qualify units and edges against independent geometry (Task 1).
5. Shared/legacy NR both execute or HUD enters NR: one source pass, separate native UI (Tasks 4-5).
