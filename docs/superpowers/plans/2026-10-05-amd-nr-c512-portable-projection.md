# AMD NR Portable C512 Projection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans with the preserved Native method. Steps use checkbox syntax for tracking.

**Goal:** Execute a bounded source-owned C512 projection on CPU and portable D3D12, comparing initial/final half storage and encoded outputs.

**Architecture:** The numerical reference uses an explicit sequential FP32 dot order within each recovered 32-channel chunk, with sixteen half-rounding boundaries. A shader implements that same declared order. A thin projection probe reuses the format probe's checked same-device queue transport and retirement machinery, with independently sized input/output buffers. The renderer and model remain disabled.

**Tech Stack:** C++23, existing FXC cs_5_1 compiler, D3D12, CTest, Python/NumPy.

**Spec:** [Approved engine design](../specs/2026-10-05-amd-nr-engine-design.md), numerical-reference/compute/operation gates; [projection record](../../amd-nr-c512-projection.md), [residual/output boundaries](../../amd-nr-c512-residual-output.md), [tensor coordinates](../../amd-nr-c512-tensor-layout.md).

Branch: `codex/amd-nr-engine`. Preserve Native and the user's direction to implement the next AMD NR step. This implements a declared portable numerical reference, not recovered WMMA internals.

## Global Constraints

- "The product consists of source-owned C++, HLSL, logical schemas, and tests."
- "FP8 is encoded storage with explicit software decode/encode; FP16 storage and required rounding boundaries are explicit."
- "A block is enabled only after its schema and CPU/GPU comparison pass."
- "It must not invent operations to fill gaps."
- Maximum 256 pixels (131,072 activation values); canonical input/residual order is `[X,Y,channel]`, Y before X. Every axis remains positive/aligned to 4 through the existing validated layout.
- Our declared dot order is ascending K within each 32-term chunk, starting FP32 +0, then add the prior half value and round to half. It is not claimed equivalent to AMD WMMA. Canonicalize arithmetic NaNs to positive half `0x7e00`; original non-finite half payloads remain unresolved.
- Initial half is residual FP8 times coefficient half plus +0, rounded before the first chunk. Absent residual means FP8 positive zeros, including multiplication by special coefficients.
- Diagnostic output has two uint32 words per activation: word0 final half in bits0..15 and E4M3 byte in bits16..23 (top byte zero); word1 initial half, zero-extended.
- Keep supplied/extracted binaries, trained weights and private evidence ignored. No original code execution, HIP dependency, game installation, full inference, merge or push.

## Review Focus

1. Chunk and residual rounding must occur at recovered boundaries: asymmetric and early-residual/32-term rounding literals in Task 1, independently ordered NumPy oracle in Task 2.
2. Empty/moved-from weights, bad counts, excessive extents and output aliasing must fail before writes/allocation: CPU sentinels and GPU rejection tests.
3. Different input/output word counts must size copies, readback and dispatch independently without regressing four format modes: transport tests, full existing suite and projection outputs.
4. Submitted resources must survive timeout, dropped handles, input mutation and probe moves; foreign jobs/queues rejected: Task 2 queue-gate and ownership tests.
5. NaNs, coefficient infinities, signed-zero initialization and encoder saturation must follow the declared policy: initial/final word assertions and special-coefficient oracle fixture.

Task 1 produces `ValidateC512ProjectionInputs(const C512TensorLayout&,span<const uint8_t> input,span<const uint8_t> residual,const C512ProjectionWeights&) noexcept -> expected<void,ProjectionEvaluationError>` and `EvaluateC512ProjectionReference` with those parameters plus `span<uint32_t> output`, returning the same expected type. Validate output count and byte overlap with input/residual/both weight views before writing. No allocation.

Task 2 consumes Task 1 validation/types and produces `class C512ProjectionProbe` with `Create(ID3D12Device*,ID3D12CommandQueue*) -> expected<C512ProjectionProbe,ProbeError>`, move-only ownership, `Submit(layout,input,residual,weights) -> expected<FormatProbeJob,ProbeError>`, and delegated `Readback(job,milliseconds)` / `Drain(milliseconds)`. Invalid inputs return `ProbeError::Count` before packaging. The canonical raw payload is input bytes, residual bytes (zeros if absent), row-major weight codes, and little-endian coefficient half words. All sizes are multiples of 4. Shader constants are logical value count and reserved zero. Output count is twice value count; dispatch work-item count is value count.
