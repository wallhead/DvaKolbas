## Files and shared types

Use namespace `TheosRenderPipeline::Upscaling` for new upscaler units. `UpscalerBackend.h` defines `Extent { uint32_t width, height; }`, `BackendKind { Dlss, Dlaa, Fsr, External }`, `Quality { Quality, Balanced, Performance, NativeAA }`, `ProviderPolicy { Analytical, Compatible }`, `ProviderInfo { uint64_t id; std::string name; }`, and `GenerationPreparationStatus { NotRequested, Succeeded, Failed }`.

`BackendConfiguration` contains backend, quality, provider policy (`Analytical` or `Compatible`), requested FG/backend, sharpness, HDR/NR/dynamic-resolution requests. `BackendDecision` contains validated backend/presentation selection plus a diagnostic. Preserve the existing INI authority: `[Settings] UpscaleType`, `[FrameGeneration] Enabled`, and `[Experimental] FrameGenerationBackend` (0 ordinary, 1 existing NVIDIA); do not add a second competing selector. Legacy `SourceDLSSGBackend` retains its NVIDIA-route validation meaning and cannot force FSR to initialize NVIDIA.

`RuntimeError` contains `ErrorKind` (MissingRuntime, WrongArchitecture, MissingExport, IncompatibleAbi, NoProvider, UnsupportedDevice, InvalidInput, ContextFailure, DispatchFailure, DeviceLost, RetirementFailure), native result code, and message. Use `Result<T> = std::expected<T, RuntimeError>` and `Result<void>` consistently. `FsrRuntime.h` holds `FsrFunctions` using the pinned header's `PfnFfx*` typedefs, without static C++ API wrappers.

`CameraMeasurements` is backend-neutral: view/projection matrices, position, near/far distances, vertical FOV radians, world-units-to-meters, depth inverted/infinite flags, identity, and reset. `UpscaleFrame` contains borrowed current D3D11 `color`, frozen `input`, `depth`, `motion`, `output`, and optional exposure/masks, extents/subrect, their formats/encoding, pre-exposure, camera measurements, source ID, delta milliseconds, jitter pixels, explicit motion convention, sharpness, and reset. Copy the world into frozen input once before source effects; the FSR bridge copies that current input into shared resources. The host retains ownership through GPU retirement. SDK-specific resources/descriptors remain inside the FSR adapter.

`GpuFrameResources` in `FSRParameters.h` contains the shared D3D12 input/output resources used by the adapter. `UpscaleOutcome` distinguishes Temporal, SpatialRecovery, SkippedInvalidInput, and Fatal. Method implementations may use private helper types, but later tasks consume only the signatures below.
